# 四个日线形态策略

> 整理自一篇回访文章中五位交易者各自坚持的单一形态。
> 其中「武汉·涨停板次日分时低吸」依赖**分时数据**且属**A股涨停板机制**，
> 不适用于美股/港股/新加坡，也无对应历史数据，故**不收录**。
> 本文只保留可用**日线数据**分析的 4 个：①成都 ③广州 ④郑州 ⑤杭州。
>
> ⚠️ 本文档仅为**形态的技术定义**，用于后续编写选股/回测脚本，**不构成任何投资建议**。

---

## 策略① 成都 —— 平台突破后的缩量回踩

**一句话**：底部长期横盘 → 放量突破平台 → 缩量回踩不破 → 回踩缩量第三天进场。

**精确条件**
1. 股价在底部**横盘超过 2 个月**（约 40+ 个交易日，箱体窄幅震荡）。
2. 某天**放量突破平台高点**（成交量明显放大，收盘站上横盘区间上沿）。
3. 突破后**缩量回调**，且回调**不跌破「突破当天那根阳线实体的一半」**
   （即不破 `突破阳线开盘价 + 实体 ×0.5`）。
4. 在**回调缩量的第 3 天**买入。

**需要的数据 / 指标**
- 日线 OHLC、成交量
- 平台区间识别（近 N 日高低点、波幅）
- 突破阳线实体中点
- 成交量放大 / 缩量的判定（对比均量）

**现有数据可行性**：✅ **够**。日线 OHLCV 全部具备。

## 策略③ 广州 —— 年线附近放量突破

**一句话**：年线下方趴半年以上 → 放量站上年线 → 连续 3 天不破年线 → 第 3 天尾盘进场。

**精确条件**
1. 股价在**年线（MA250）下方运行超过半年**（约 120+ 个交易日收盘价 < MA250）。
2. 某天**突然放量站上年线**（收盘价上穿 MA250，且成交量明显放大）。
3. 此后**连续 3 天收盘价都不跌破年线**。
4. 在**第 3 天尾盘**进场。

**需要的数据 / 指标**
- 日线收盘、成交量
- **年线 MA250**（250 日简单移动均线）
- 成交量放大判定

**现有数据可行性**：✅ **已可用**（历史已补到 2023-01-03，约 3.5 年，足够算 MA250 + 半年判断）。
- MA250 需要信号日之前 **250 个交易日**；「年线下方半年」再往前 **~120 个交易日**；
- 已纳入扫描器 `scanner.py`（`scan_s3`），输出 `strategy3_annual_line.csv`。

## 策略④ 郑州 —— 下跌趋势末期的日线底背离

**一句话**：创新低但 MACD 绿柱缩短（底背离），日线级别确认后，分三次建仓。

**精确条件**
1. 处于**下跌趋势末期**：股价**创出新低**（价格低于前一个低点）。
2. 但同期 **MACD 出现底背离**：价格新低，而 **MACD（或 DIF/柱状值）不再创新低**
   （绿柱缩短、动能衰减）。
3. 等**日线级别底背离确认**后进场。
4. **分三次建仓**（分批，不一次打满）。

> 原文另有「分时图出现明显抗跌」作为辅助确认——该条依赖**分时数据**，
> 现有日线无法覆盖，作为可选加分项，不作为主条件。

**需要的数据 / 指标**
- 日线收盘（算 **MACD**：EMA12、EMA26、DIF、DEA、柱状 MACD）
- 价格摆动低点识别（swing low）
- 背离判定（价格新低 vs MACD 未新低）

**现有数据可行性**：✅ **核心够**。MACD 由日线收盘可算，底背离可判定。
（仅「分时抗跌」这个辅助条件缺分时数据。）

## 策略⑤ 杭州 —— 放量突破前高后回踩前高不破

**一句话**：前高画线 → 放量冲破 → 回踩这条线不破就接 → 跌破无条件走人。

**精确条件**
1. 找到**前期高点**（前高），在该价位画一条水平线。
2. 股价**放量向上突破前高**（成交量放大，收盘价 > 前高）。
3. 突破后**回踩到前高这条线**：
   - **踩线不破**（回踩到前高附近获得支撑）→ **买入**。
   - **跌破前高线**（收盘明显跌回线下）→ **无条件止损离场**。

**需要的数据 / 指标**
- 日线 OHLC、成交量
- 前高识别（前期显著高点 / swing high）
- 成交量放大判定
- 明确的止损规则（跌破前高线）

**现有数据可行性**：✅ **够**。日线 OHLCV 全部具备。

## 策略⑥ 缩量 + 十日线向上（量能择时）

**一句话**：成交量缩到低位 + 十日均线向上 → 买入；成交量接近区间最大量 → 卖出。

**精确条件**
- **买入**：当日成交量 ≤ **近 120 日最低量 × 1.08**（接近真地量，非"低于均量"）**且**
  十日均线(MA10)向上（今日 > 昨日）。信号只在"新出现"时记录，且两次信号间隔 ≥ **10 交易日冷却**（避免密集重复）。
  （注：早期版本用"低于30日均量70%"太松，导致信号泛滥，已改为地量口径。）
- **卖出/离场**（满足其一）：
  - **天量卖点（按股自适应）**：当日成交量 ≥ 该股**近 250 日成交量的 99 分位数**
    （即进入自己历史最高 1% 的量——波动大的股门槛自然高、安静的股门槛低）；
  - **近最大量**：当日成交量 ≥ 近 120 日最大量 × 0.9；
  - **保护止损**：跌破买入价 8%。
  > 回测显示天量越低越易砍掉还在涨的赢家，故默认 5 倍(真天量)；`s6_sky_mult` 可调。

**量能参考**（每股不同，见 `成交量参考.csv`）：最近 **360 / 120 / 90 / 30** 天的
**最低 / 平均 / 最大** 成交量，及当前量能在 120 日区间的位置。

**需要的数据 / 指标**：日线成交量、MA10、多窗口量能统计。

**现有数据可行性**：✅ 够。回测(288 笔·严地量1.08+10日冷却)：胜率 ~56%、盈亏比 ~2.1、平均 +3.3%；
在高波动成长股(泡泡玛特、SK海力士、AMD、NVDA、有色)上尤佳。
